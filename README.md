# CSE 321 - Programming II

An autonomous Mars colony management and simulator.

## Project Structure
* src/ — Source code implementations.
* * agents/
  * colony/
  * common/
  * emergencies/ - Emergency handling module (see details in [src/emergencies/README.md](https://github.com/abdelrhman-khaled13/MARS-OPS/blob/main/src/src/emergencies/README.md)).
  * environment/
  * facilities/
  * missions/
  * resources/
  * main.java
* docs/ - UML diagrams and project documentation.

---

The simulator manages colony personnel, robotic units, facilities, resources, active missions, and emergency handling workflows across simulated time steps.
